Project 2 - Text Analysis

Files:
- analyze_text.c: contains main() and handles user interaction.
- analysis.c: contains one function for each required analysis.
- analysis.h: function declarations shared by the program.
- clean_word.c: implementation of cleanWord().
- clean_word.h: declaration for cleanWord().
- Makefile: builds the executable analyzeText.
- P2_pseudocode.txt: pseudocode for the program.

Compilation:
Run:
    make

This creates:
    analyzeText

Run the program:
    ./analyzeText

The program asks for an input text file, an analysis option, and an
output file. Option 4 also asks for the word to find.
