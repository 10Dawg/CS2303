PROJECT 2 - TEXT ANALYSIS PSEUDOCODE

MAIN
1. Display "Welcome to the text analyzer."
2. Ask the user for the input file name.
3. Open the input file for reading.
4. If the file cannot be opened:
   a. Print "[file name] not found."
   b. Exit the program.
5. Display the four analysis choices.
6. Read the user's choice.
7. While the choice is not 1, 2, 3, or 4:
   a. Print "Invalid option."
   b. Print the four choices again.
   c. Read the choice again.
8. If the choice is 4:
   a. Ask for the word to find.
9. Ask for the output file name.
10. Open the output file for writing.
11. Call the function that matches the selected analysis.
12. Close the input and output files.
13. End the program.

LETTER COUNT
1. Create an integer array with 26 elements and initialize all elements
   to zero.
2. While another word can be read with fscanf():
   a. Clean the word with cleanWord().
   b. Loop through each character in the cleaned word.
   c. If the character is a letter, convert it to lowercase.
   d. Calculate its array position with:
      index = letter - 'a'
   e. Increase the count at that index.
3. Print each letter and its count to the output file.

WORD LENGTH COUNT
1. Create an integer array with 16 elements and initialize all elements
   to zero.
2. While another word can be read with fscanf():
   a. Clean the word with cleanWord().
   b. Find its length using strlen().
   c. If the length is zero, do not count it.
   d. If the length is 16 or greater, increase the last array element.
   e. Otherwise, increase the element corresponding to its length.
3. Print the counts for lengths 1 through 15.
4. Print the final element as the 16+ category.

TOTAL WORDS
1. Set total to zero.
2. While another word can be read with fscanf():
   a. Clean the word with cleanWord().
   b. If the cleaned word is not empty, increase total.
3. Print the total number of words.

WORD FINDER
1. Copy the target word into a local character array.
2. Clean the target word with cleanWord().
3. Convert the target word to lowercase.
4. Set the match count to zero.
5. While another word can be read with fscanf():
   a. Clean the word with cleanWord().
   b. Convert the word to lowercase.
   c. If the cleaned word matches the target word, increase the count.
6. Print the target word and the number of matches.

MAKE LOWER
1. Start at the first character of the word.
2. While the current character is not the null terminator:
   a. Convert the character to lowercase.
   b. Move to the next character.
3. End the function.

CLEAN WORD
1. Start with read and write positions at zero.
2. Examine each character in the input word.
3. If the character is a letter, copy it to the write position.
4. Increase the write position when a letter is copied.
5. Continue until the null terminator is reached.
6. Add a null terminator at the new end of the word.
