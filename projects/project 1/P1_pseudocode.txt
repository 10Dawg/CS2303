int ConvertScore(float score): take in a score for a project and return a value corresponding to ME(0), RN(1), or NG(2)
void printSummary(float cmpPoints, int projectVals[3]): take in CMP total and number of ME/RN/NG, print summary of grade and information about raising the grade
float subtractMinZero(float a, float b): helper function for common calculation, subtracts b from a, returning 0 if the result would be negative
