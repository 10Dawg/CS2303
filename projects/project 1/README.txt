Grade Calculator program for CS2303

This program takes user input about their current grades in CS2303, calculates the
student's current letter grade, and tells them how much more credit they need to earn
to increase that letter grade.



To compile:
gcc grade_calculator.c -o grade_calculator


To run:
./grade_calculator

The program will prompt for a total points value which should be a float between 0 and 1000 (inclusive),
followed by prompting for 5 floats between 0 and 100 (inclusive). A summary of the grade will then be printed followed
by a table showing what needs to be increased to inprove the grade.
